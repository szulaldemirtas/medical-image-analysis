# Breast Lesion Classification in Mammography

Classifies mammograms from the CBIS-DDSM dataset as benign, malignant or benign-without-callback, comparing a simple CNN, ResNet50, a U-Net encoder and a Swin Transformer in PyTorch with class-imbalance handling, 5-fold cross-validation and paired statistical tests. Team project with Beyza Türkmen and Perihan Yıldız Topal for the Medical Image Analysis course (COMP448) at Koç University, 2025; see `report.pdf` for full results.
